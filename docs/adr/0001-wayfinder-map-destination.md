# Wayfinder map destination is a decisions-only IA spec for all three sections

The site's content isn't yet specified, and building it directly would mean discovering structure mid-implementation. We decided the wayfinder map's destination is a full content/information-architecture spec covering all three sections (Intro to AI, Backend dev example, Frontend dev example), stopping at decisions rather than pulling implementation into the map — a separate build effort executes the spec afterward. We considered scoping to a narrower first slice (e.g. Intro to AI only) but rejected it: the three sections are already named and interrelated, so specifying only one risks decisions that don't hold up once the others are drafted.

One section can't be fully specified yet: the Frontend dev example's screenshot narrative depends on screenshots captured *while* the site is built, so that detail stays in the map's fog until the build produces material to curate.
