# AI Coding Session Website

## Purpose

This repository is an interactive website used as teaching material
for an AI coding session.

This is hosted on github. So pure **js/ts**

See ProjectBrief.md for detail

## Design philosophy

Avoid generic AI-generated UI.

Do NOT automatically use:
- purple gradients
- excessive rounded cards
- glassmorphism
- unnecessary shadows
- generic SaaS dashboards
- excessive icons
- decorative animations
- meaningless statistics
- "AI-looking" visual patterns

Every major visual element must have a communication purpose.

Prefer:
- strong visual hierarchy
- deliberate typography
- meaningful whitespace
- editorial composition
- visual storytelling
- restrained animation
- real-world product references
- distinctive but coherent visual language

## Animation

Animations must communicate relationships or transitions.

Do not animate elements merely because animation is possible.

Prefer:
- progressive disclosure
- scroll-triggered transitions
- code → result transitions
- architecture transformations
- interactive diagrams
- before/after comparisons



## Code

Keep the implementation simple.

Prefer small reusable components/functions.

Do not introduce a framework or dependency unless it provides
a clear benefit to the teaching material.

## Content

Never invent details about the real project.

Use placeholders where sensitive information has been removed.
