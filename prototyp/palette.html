Stateless sessions

A normal model interaction does not, on its own, mean the model remembers another independent session. Each call starts from context and produces a response — nothing more persists unless an application adds it. 

Session A
   ↓
Context
   ↓
Response

Session B
   ↓
New context   ← no memory of Session A
   ↓
Response
